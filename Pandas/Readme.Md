# Pandas

A collection of practical **Pandas implementations, data manipulation techniques, feature extraction workflows, and real-world data analysis** using Python.

## 📂 Contents

### 📊 Pandas Core Operations

[`Pandas_Core_Operations.ipynb`](./Pandas_Core_Operations.ipynb)

Covers essential Pandas operations including:

* Series and DataFrames
* Data selection and indexing
* Filtering and sorting
* Handling missing values
* DataFrame manipulation
* Merging, joining, and concatenation
* GroupBy and aggregation
* Pivot tables
* Crosstabs
* Applying functions
* Data analysis operations

### 🔍 Feature Extraction with Pandas

[`Feature_Extraction_with_Pandas.ipynb`](./Feature_Extraction_with_Pandas.ipynb)

Demonstrates extracting useful information from raw data and transforming it into analyzable features.

Includes:

* Feature extraction from text-based data
* Data transformation
* Episode count extraction
* Time-related feature extraction
* Value counting and ranking
* Data analysis using extracted features

### 🌍 Countries Data Analysis

[`Countries_Data_Analysis.ipynb`](./Countries_Data_Analysis.ipynb)

A practical data-analysis notebook working with country-based data.

Includes:

* Data exploration
* Filtering and conditional queries
* Sorting
* Aggregation
* Missing-value handling
* Data selection and manipulation
* Statistical analysis
