## 📂 Contents

### 📊 Pandas Core Operations

A practical implementation of essential Pandas operations and DataFrame workflows.

- Filtering and sorting

- Merging, joining, and concatenation
- GroupBy and aggregation
- Pivot tables
- Crosstabs
- Applying functions
- Data analysis operations

### 🔍 Feature Extraction with Pandas

[`Feature_Extraction_with_Pandas.ipynb`](./Feature_Extraction_with_Pandas.ipynb)

Practical workflows for extracting useful information from raw data and transforming it into analyzable features.

- Data transformation
- Episode count extraction

- Value counting and ranking
- Data analysis using extracted features

- Statistical analysis
