# Projects

A collection of end-to-end projects covering **Data Analysis, Data Science, Machine Learning, Artificial Intelligence, and Generative AI**.

Each project focuses on applying technical concepts to practical problems through data, models, applications, and AI systems.

## 📂 Project Categories

### 📊 Data Analysis

Projects focused on data exploration, cleaning, transformation, visualization, statistical analysis, and extracting actionable insights.

**Technologies:**
Python · Pandas · NumPy · Matplotlib · Seaborn · SQL

---

### 🤖 Machine Learning

Projects involving data preprocessing, feature engineering, model development, evaluation, and optimization.

**Technologies:**
Python · NumPy · Pandas · Scikit-learn · Matplotlib · Seaborn

---

### 🧠 Artificial Intelligence

Projects involving intelligent systems, computer vision, natural language processing, and AI-based applications.

**Technologies:**
Python · OpenCV · NLP · Deep Learning · TensorFlow · PyTorch

---

### ✨ Generative AI

Projects built around modern generative AI systems, including LLM applications, RAG systems, AI agents, and multimodal AI.

**Technologies:**
Python · LLMs · RAG · Vector Databases · APIs · LangChain · AI Agents

---

### ⚙️ AI Engineering

End-to-end AI applications combining models, APIs, databases, frontend systems, and deployment.

**Technologies:**
Python · FastAPI · React · Next.js · Docker · Cloud · APIs · Databases
