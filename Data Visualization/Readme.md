# Data Visualization

A collection of practical **data visualization techniques and analysis projects** using Python.

## 📂 Contents

### 📊 Matplotlib Fundamentals

[`Matplotlib_Fundamentals.ipynb`](./Matplotlib_Fundamentals.ipynb)

Covers fundamental visualization techniques using Matplotlib, including:

* Line plots
* Scatter plots
* Bar charts
* Histograms
* Box plots
* Subplots
* Figure customization
* Plot formatting and styling
* Saving visualizations

[`Seaborn_Distribution_Plots.ipynb`](./Seaborn_Distribution_Plots.ipynb)

Covers distribution-based visualizations using Seaborn:

* Histograms
* Distribution plots
* Joint plots
* Pair plots
* Rug plots

[`Seaborn_Matrix_Plots.ipynb`](./Seaborn_Matrix_Plots.ipynb)

Covers matrix-based visualizations:

* Heatmaps
* Clustermaps
* Pivot-table visualizations
* Correlation analysis

### 📉 Seaborn Regression Plots

[`Seaborn_Regression_Plots.ipynb`](./Seaborn_Regression_Plots.ipynb)

Covers regression-based visualizations using Seaborn:

* Regression plots
* `lmplot()`
* Relationship analysis
* Trend visualization
